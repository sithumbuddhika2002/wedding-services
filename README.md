# 🌟 Magical Moments

A modern, high-performance website built with **Next.js** and **Tailwind CSS**, offering **exquisite event decorations**, **stunning photography**, and **cinematic videography** services to make your special day truly magical.

![Magical Moments Banner](./public/banner.jpg) <!-- Optional: Add a banner image -->

---

## ✨ Features

- 🎨 Sleek, modern UI with Tailwind CSS
- 📸 Image & video gallery with lightbox/modal support
- 🎥 Cinematic video preview support
- 📝 Dynamic service listings (decorations, photography, videography)
- 💬 Testimonials slider
- 📱 Fully responsive (mobile, tablet, desktop)
- 📧 Integrated contact form (API route or third-party service)
- ⚡ Optimized for SEO & performance

---

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: Framer Motion / AOS (optional)
- **Deployment**: Vercel / Netlify
